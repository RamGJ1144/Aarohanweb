# Aarohan – Learning Schedule Website

## 📌 Project Overview

**Aarohan Learning Schedule** is a web-based learning platform that helps students organize their learning journey through a structured course roadmap, daily training schedule, assessments, and practical project activities.

The website provides a learning plan covering Full Stack Python development during the first three months, followed by AI and Machine Learning concepts during the next three months.

## 🌐 Live Demo

**Website:** https://aarohanweb.netlify.app/pages/schedule

## ✨ Features

- **Course Roadmap:** Structured six-month learning plan for Full Stack Python and AI/ML.
- **Full Stack Python:** Learn HTML, CSS, JavaScript, Python, Django/Flask, MySQL, APIs, and Git/GitHub.
- **AI & Machine Learning:** Introduction to Python, mathematics, data handling, ML algorithms, model evaluation, and AI concepts.
- **Daily Training Schedule:** Organized sessions for theory, coding practice, laboratory work, and communication skills.
- **Schedule Search:** Search for sessions, topics, or descriptions.
- **Daily and Weekly Quizzes:** Assess learning progress and understanding.
- **Project-Based Learning:** Includes project reviews, presentations, feedback, and practical implementation.
- **Online Deployment:** Accessible through the live website hosted on Netlify.

## 📚 Learning Roadmap

### Phase 1: Full Stack Python Development (First 3 Months)

1. HTML – Web page structure and forms.
2. CSS – Styling, layouts, and responsive design.
3. JavaScript – Programming fundamentals and DOM manipulation.
4. Python – Syntax, functions, collections, and problem-solving.
5. Django / Flask – Backend web development.
6. MySQL – Database management and queries.
7. APIs – Request and response handling.
8. Git & GitHub – Version control and project collaboration.
9. Projects – Practical development and final project implementation.

### Phase 2: AI & Machine Learning (Next 3 Months)

1. Python Basics
2. Mathematics Fundamentals
3. Data Handling and Preparation
4. Machine Learning Fundamentals
5. ML Algorithms – Classification and Regression
6. Model Training, Testing, and Evaluation
7. Artificial Intelligence Concepts
8. Python Libraries for Data Science and Machine Learning
